# SignalKey v0.1.0-alpha.2 — TILE T1 engineering handoff

**Pre-release · engineering concept · not for manufacture**

This release publishes the local-first SignalKey desktop companion at `0.1.0-alpha.2` alongside the active TILE T1 enclosure and manufacturing-development handoff. It is intended for software evaluation, design review and prospective manufacturing-partner assessment.

## Included

### Desktop companion

- Local profile, gesture and workflow configuration with persistent run history.
- Explicit native review before newly enabled or changed execution details may run.
- Real local command execution with observed process result, cancellation and bounded output.
- Interrupted-run recovery that records unresolved work as interrupted and never retries it automatically.
- Duplicate execution admission protection, virtual-device simulation and local SDK/CLI support.

### TILE T1 enclosure handoff

- Larger `128 × 108 × 52 mm` parametric enclosure study for the documented P3 bench stack.
- Native OpenSCAD source, six printable STL/3MF prototype parts, clearance coupon and export-verification record.
- Dimensioned, exploded and section drawing sheets; part BOM; assembly instructions; blank physical inspection record.
- Separate prototype-print and production/DFM route, including serviceability and factory-development constraints.
- Manufacturer partnership note defining the remaining DFM/DFA, sourcing, tooling, validation and release scope.

## Important limitations

- No physical SignalKey unit, printed T1 enclosure, P3 harness, USB connection, button, LED optic or tactile mechanism has been validated.
- T1 component positions are bounded engineering envelopes, not received-part measurements.
- No STEP B-rep, released schematic/layout, authorized firmware image, production tooling, factory test fixture, certification, first article or production approval is included.
- The amber prototype optical guide may affect RGB status presentation and needs real optical evaluation.
- This desktop package is unsigned and portable; it is not an installer or public production distribution.
